# MyDesktop 桌面分区
Windows 11 桌面整理工具：用半透明的分区把桌面图标分门别类地收纳起来，让桌面整洁有序。图标只是换个地方显示，文件始终留在桌面上；退出 MyDesktop，桌面就恢复原样。
## 一、功能简介
- **分区收纳**：在桌面上建立半透明的分区，把图标分类放进去，此电脑、回收站等系统图标也能放。分区可以随意拖动、调整大小并自动对齐；双击标题栏卷起，鼠标移上去自动展开；可以锁定，防止误动；按 Win+D 显示桌面时分区依然可见
- **一键整理**：按快捷方式、文件夹、文档、图片、影音、压缩包、程序等类型，一次把桌面图标归入对应的分区；还可以开启自动整理，新下载的文件会自动归类；整理规则可以自己修改
- **文件夹映射**：分区也可以直接显示任意文件夹的内容，比如「下载」文件夹，不用再打开资源管理器
- **用法和系统桌面一样**：双击打开、右键菜单、重命名、删除、复制粘贴、框选、方向键和首字母定位都和平时一样；图标可以在分区之间、分区和桌面之间、分区和资源管理器之间随意拖放，拖到文件夹、程序、回收站的图标上也和资源管理器里一样。没放进分区的图标仍按 Windows 自己的排列方式显示，并自动避开分区
- **双击桌面隐藏**：双击桌面空白处即可隐藏或显示，可以选择隐藏「图标和分区」「只有桌面图标」或「只有分区」
- **画框新建分区**：在桌面空白处按住鼠标右键拖出一个框，就在那里新建一个分区
- **外观随心**：每个分区都能单独设置颜色、透明度、图标大小、列表视图和排序方式
- **桌面右键菜单**：桌面空白处的右键菜单里有 MyDesktop，可以新建分区、一键整理、切换双击隐藏的对象、打开设置
- **放心使用**：分区只记录哪些图标归它，不会移动任何文件；退出 MyDesktop 后桌面与原来完全一样，程序意外关闭时桌面图标也会自动恢复
## 二、安装与卸载
### 2.1 安装
支持 Windows 11（64 位）。
1. 打开[发行版页面](https://github.com/mizepeng/my-desktop/releases/latest)，下载 `MyDesktop-Setup-版本号.exe`
2. 双击安装包，按提示完成安装。如果出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」
3. 点「完成」后 MyDesktop 会自动启动，首次启动时会询问是否一键整理桌面。之后在任务栏右下角的通知区域能找到它的图标（可能收在「^」里），右键图标可以新建分区、打开设置或退出

安装包会顺带完成下面这些设置，不需要另外操作：
- 电脑上缺少 MyDesktop 需要的运行环境（微软的 .NET 10 桌面运行时）时，自动下载并安装，约 57 MB
- 把 MyDesktop 加入桌面右键菜单
- 开机自动启动（安装时可以取消勾选，之后也能在托盘菜单里开关）
### 2.2 卸载
在「设置 → 应用 → 已安装的应用」里找到「MyDesktop 桌面分区」，点「卸载」。卸载后桌面恢复原样，分区设置会保留，重新安装后可以接着使用。
