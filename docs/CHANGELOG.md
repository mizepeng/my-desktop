# 更新日志
## 1.5.0（2026-10-23）
- 新增：设置「分区」页可以打开「单击打开图标」，分区和桌面上的图标单击就能打开
- 新增：映射分区的标题栏菜单里可以复制文件夹路径
- 改进：分区的滚动条不再占用宽度，平时隐藏，鼠标移进分区时才显示
- 改进：拖动图标时和资源管理器一样显示提示，拖到程序、文件夹上会显示「用 xx 打开」「移动到 xx」；只是挪位置时不再显示多余的箭头
- 改进：在桌面上挪图标时，只有拖到另一个图标的图片上才会交给它处理，落在名称或空隙上只挪位置，不会误把文件交给程序打开
- 修复：把桌面上的图标拖到空位上，有时会跳到旁边的格子
- 修复：拖着图标经过分区再出来，拖动的预览图会消失
- 修复：开启删除确认后，在桌面上多选图标删除时，确认框一直闪烁或被挡住
## 1.4.2（2026-10-23）
- 修复：从 PeaZip 窗口把压缩包里的文件拖到分区上，只留下一个空的 source 文件夹，解压出的文件没有出现

## 1.4.0（2026-10-22）
- 新增：详细信息视图可以拖动表头的分隔线调整列宽，每个分区单独记住；双击分隔线恢复自动宽度
- 新增：设置里加了「使用说明」页，按功能分组列出常用操作
- 改进：桌面图标和分区的文字加了一层淡描边，浅色壁纸上更清楚，不再发虚
- 改进：左键框住图标时只做选择，不再弹出新建分区的菜单；按住 Alt 框选才新建分区并收进框住的图标
- 改进：以管理员身份运行时提示一次：这时图标右键菜单会缺少火绒、WinRAR 等软件的菜单项
- 修复：桌面上按 Ctrl+V、Ctrl+Z 没有反应；现在和系统桌面一样可以粘贴、撤销，Ctrl+Y 恢复
- 修复：复制桌面上的文件后在原处粘贴，提示文件名相同而失败；现在和系统一样自动命名为「- 副本」
- 修复：详细信息视图调大字号或换字体后，修改日期只显示到月份

- 改进：设置里的下拉框不会再被鼠标滚轮误改，第一次展开也不再卡一下

## 1.0.0（2026-10-05）
首个发布版本：
- 分区收纳：半透明分区分类收纳桌面图标，可拖动、调整大小、自动对齐；双击标题栏卷起、悬停展开，贴在屏幕下边或左右边的分区朝那条边收起

- 操作和系统桌面一样：打开、右键菜单、重命名、删除、复制粘贴、框选、拖放

- 安装包自动安装 .NET 10 桌面运行时、加入桌面右键菜单，可选开机自动启动
