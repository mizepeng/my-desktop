# 更新日志
## 1.0.7（2026-10-06）
- 修复：开着 Wallpaper Engine 时（NVIDIA 游戏覆盖层的透明窗口会盖在桌面上），桌面上的左键框选、右键框选和右键画框新建分区都不起作用
- 修复：删除分区后，或者以管理员身份运行的程序在前台时，在桌面上右键没有反应，要先左键点一下桌面才恢复
## 1.0.6（2026-10-05）
- 改进：分区里的图标和桌面上的图标共用一组选择，规则与系统桌面一致：单击只选这一个，按住 Ctrl/Shift 单击可以跨分区和桌面多选，点任意空白处全部取消；删除、复制、拖动等对所有选中的图标一起生效
- 修复：系统「新应用的保存位置」设在非系统盘时，桌面右键菜单扩展包无法随程序更新
## 1.0.5（2026-10-05）
- 修复：分区里的图标和桌面上的图标能同时处于选中状态；现在整个桌面只保留一处选择，在分区或桌面上操作时，其他地方的选择自动取消
- 修复：升级后桌面右键菜单扩展包有时注册失败、从应用列表里消失；扩展包的版本号现在与程序一致
- 新增：卸载时可以选择删除还是保留分区设置和备份，默认保留
- 改进：自动更新下载的安装包用完即清理，卸载时也一并删除
## 1.0.4（2026-10-05）
- 修复：关闭「右键画框新建分区」后，在桌面上右键拖动恢复为和系统一样的框选，松开后弹出所选图标的右键菜单
- 改进：每次启动后都会检查一次新版本（原来一天只检查一次）
## 1.0.3（2026-10-05）
- 新增：分区毛玻璃背景，分区后面的壁纸模糊后透出来；用动态壁纸时自动改为半透明。可在「设置 → 外观」关闭，单个分区可在右键菜单里单独设置
- 新增：多显示器布局记忆，拔掉外接显示器时分区挪到看得见的地方，接回后自动回到原处
- 新增：备份与恢复，一键整理、删除分区之前自动备份，也可以手动备份或导出；在「设置 → 备份」里一键恢复
- 新增：升级完成后在通知区域提示
- 新增：「设置 → 关于」里可以直接反馈问题
## 1.0.2（2026-10-05）
- 新增：自动更新。有新版本时提示，确认后自动下载、核对安装包签名、安装并重新启动；托盘菜单和「设置 → 关于」里可以手动检查更新，也可以关闭自动检查
## 1.0.1（2026-10-05）
- 修复：桌面获得焦点时，Win+E、Win+I、Win+D 等 Win 组合键失效
- 修复：切换系统缩放比例后，桌面图标间距过大或过挤、分区标题栏大小不对
- 改进：切换缩放比例后分区随之等比例缩放，图标排布保持不变；每种缩放比例下的分区布局分别记住，切回时原样恢复
## 1.0.0（2026-10-05）
首个发布版本：
- 分区收纳：半透明分区分类收纳桌面图标，可拖动、调整大小、自动对齐；双击标题栏卷起、悬停展开，贴在屏幕下边或左右边的分区朝那条边收起
- 一键整理：按类型把桌面图标归入对应分区，可自动整理新出现的文件
- 文件夹映射：分区直接显示任意文件夹，双击文件夹在分区内浏览
- 操作和系统桌面一样：打开、右键菜单、重命名、删除、复制粘贴、框选、拖放
- 双击桌面空白处隐藏图标和分区；按住右键画框新建分区
- 文件始终留在桌面上，退出后桌面恢复原样
- 安装包自动安装 .NET 10 桌面运行时、加入桌面右键菜单，可选开机自动启动
