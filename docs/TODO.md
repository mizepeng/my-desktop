## 不做

- **日历、天气、待办、便签等桌面小组件**（B 站 致命小蛮腰等多人）：不属于桌面整理的范畴，MyDesktop 主打小而精，不做。
- **开机后 MyDesktop 晚约 30 秒出现**（B 站 予芖等）：MyDesktop 本身不到 1 秒就能显示分区，慢在 Windows 对 Run 项等常规开机启动项的排队延迟（实测登录后 27～48 秒才被拉起）。1.0.9 用过的登录计划任务能早约 30 秒，但它启动的进程在 Job 里，打开的程序会继承这个 Job 出问题（GitHub #9），1.3.2 已舍弃；Windows 服务、改系统启动延迟等办法代价都太大。维持 Run 项（Max 2026-11-15 定）。
- **从任务视图回到桌面时图标和分区晚出现约半秒**（B 站 三忠四无）：系统行为，不是 bug。
